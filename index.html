07 — Performance

How I approach performance

Performance work starts with field and lab measurement, not guesses: Lighthouse in CI and Datadog RUM in production, then the specific Core Web Vital that is failing. On Sonny's Quivio that path took LCP from 3.8s to 2.6s and cut the initial bundle by 25%; on the UPSC portal, server rendering, pagination and caching reduced page load time by 20%.

08 — Accessibility

Accessibility, demonstrated

WCAG 2.1 AA is part of how I ship, not an audit at the end. On the CWC healthcare platform that approach reduced accessibility defects by 20%. This site is built the same way — semantic landmarks, one h1 per page and an ordered heading structure, visible focus rings, 44px touch targets, keyboard paths through every control, and preferences you can change below.
